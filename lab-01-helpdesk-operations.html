Active Directory Help Desk Access Control

Lab 01 – Active Directory Help Desk Operations

July 2026

Objective

Perform standard support tasks in an existing Active Directory domain, including account recovery, group-based access control, and basic user lifecycle management.

Environment

  • Domain Controller: DC01.lab.local (192.168.1.10)
  • Domain: lab.local
  • Users: Bob, John
  • Security group: Share-Access

What was done

Used the existing lab.local domain to simulate common help desk operations. Reset Bob’s password and validated authentication. Created a security group for access control, added Bob to the group, and assigned share permissions on C:\LabShare to that group only.

Password reset for Bob

Authentication validated as lab\bob

Bob added to Share-Access

Bob membership includes Share-Access

Verified the permission model by testing access as Bob and John. Bob could list the share; John received access denied.

Bob access to \\DC01\LabShare succeeded

John access denied to \\DC01\LabShare

New user John created for onboarding simulation

Result

  • Password reset and authentication validation completed
  • Group-based share access configured
  • Access contrast confirmed (Bob allowed, John denied)
  • Basic user onboarding demonstrated

Notes

This lab focuses on operational support work inside Active Directory rather than exploitation. The main value is structured account administration and group-based permission handling in a live domain environment.
