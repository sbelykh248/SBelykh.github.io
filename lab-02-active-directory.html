Active Directory AS-REP Roasting Windows Server

Lab 02 – Active Directory Setup + AS-REP Roasting

Date: July 2026 · Difficulty: Intermediate · Status: Completed

Objective

Build a functional Active Directory environment from scratch and perform a real authentication attack (AS-REP Roasting) against a domain user.

Environment

  • Domain Controller: Windows Server 2022 (DC01.lab.local) – 192.168.1.10
  • Domain-joined Client: Windows 11 (V2)
  • Attacker: Kali Linux
  • Domain: lab.local

Methodology

  1. Install and configure Windows Server as a Domain Controller
  2. Create domain lab.local
  3. Join a Windows 11 machine to the domain
  4. Create Organizational Unit, users, and security group
  5. Configure a user for AS-REP Roasting
  6. Execute the attack from Kali using Impacket

Walkthrough

1. Domain Controller Setup

Installed Windows Server 2022, assigned static IP 192.168.1.10, promoted the server to a Domain Controller, and created the forest root domain lab.local.

2. Domain Join

Configured a Windows 11 machine with DNS pointing to the Domain Controller and successfully joined it to lab.local.

3. Active Directory Objects

  • Created OU: LabUsers
  • Created users: Alice Admin and Bob User
  • Created security group: Lab-Admins
  • Added Alice to Lab-Admins

4. AS-REP Roasting

Configured Bob with “Do not require Kerberos preauthentication” and executed the attack:

impacket-GetNPUsers lab.local/bob -no-pass -dc-ip 192.168.1.10

Successfully retrieved Bob’s AS-REP hash.

Results

  • Fully functional Active Directory domain created
  • Windows 11 client successfully domain-joined
  • AS-REP Roasting attack completed with valid hash obtained

Tools Used

Oracle VirtualBox · Windows Server 2022 · Windows 11 · Kali Linux · Impacket · Active Directory Users and Computers

Lessons Learned

Building Active Directory from scratch provides deep understanding of domain structure, authentication, and common misconfigurations. AS-REP Roasting demonstrated how a single account setting can expose credentials to offline cracking.
