Active Directory AS-REP Roasting Windows Server

Lab 02 – Active Directory Setup + AS-REP Roasting

Date: July 2026 · Difficulty: Intermediate · Status: Completed

Objective

Build a functional Active Directory environment from scratch and perform a real authentication attack (AS-REP Roasting) against a domain user.

Environment

  • Domain Controller: Windows Server 2022 (DC01.lab.local) – 192.168.1.10
  • Domain-joined Client: Windows 11
  • Attacker: Kali Linux
  • Domain: lab.local

Walkthrough

1. Domain Controller Setup & Verification

Server Manager – AD DS role installed

AD DS role confirmed on DC01

System Properties – DC01.lab.local

PowerShell confirmation of domain lab.local

ipconfig /all – DC01 network configuration

2. Domain Join & Active Directory Objects

Windows 11 successfully joined to the domain. Created LabUsers OU, users Alice Admin & Bob User, and the Lab-Admins security group.

3. AS-REP Roasting

Configured Bob without Kerberos preauthentication and successfully retrieved the AS-REP hash using Impacket.

Results

  • Fully functional Active Directory domain created
  • Windows 11 client successfully domain-joined
  • Users, OU, and security group created
  • AS-REP Roasting attack completed with valid hash obtained

Tools Used

Oracle VirtualBox · Windows Server 2022 · Windows 11 · Kali Linux · Impacket · Active Directory Users and Computers

Lessons Learned

Building Active Directory from the ground up provides deep understanding of domain structure and authentication. AS-REP Roasting demonstrated how a single account misconfiguration can expose credentials to offline attacks.
