Active Directory AS-REP Roasting

Lab 02 – Active Directory + AS-REP Roasting

July 2026

Objective

Stand up a working Active Directory environment and demonstrate a practical AS-REP Roasting attack against a misconfigured account.

Environment

  • DC: Windows Server 2022 (DC01.lab.local – 192.168.1.10)
  • Client: Windows 11 joined to the domain
  • Attacker: Kali Linux
  • Domain: lab.local

What was done

Installed and promoted a Windows Server 2022 box to a domain controller, created the lab.local domain, and joined a Windows 11 machine to it. Built out a basic OU with two users (Alice and Bob) and a security group. Bob was configured without Kerberos pre-authentication.

Server Manager showing AD DS role

Network configuration on the DC

From Kali, used Impacket’s GetNPUsers to request a TGT for Bob. The attack returned a usable hash.

Result

  • Domain controller and client are functional
  • AS-REP Roasting succeeded
  • Hash recovered for offline cracking

Notes

This is a common misconfiguration. Any domain user can pull the hash if pre-authentication is disabled. Easy to overlook, easy to exploit.
