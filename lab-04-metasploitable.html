Lab 01 – Metasploitable Exploitation

July 2026

Objective

Build a basic offensive lab and complete a full attack chain against Metasploitable 2, from initial access to root-level post-exploitation.

Environment

  • Attacker: Kali Linux
  • Target: Metasploitable 2
  • Platform: Oracle VirtualBox
  • Network: Bridged

Kali Linux environment

What was done

Set up both machines on the same network. Verified basic connectivity and ran service discovery against the target. Identified the UnrealIRCd service and used the corresponding Metasploit module to exploit it.

Apache running on Kali

Custom lab page

The exploit returned a root Meterpreter session. From there, basic post-exploitation was performed — system info, user enumeration, and dumping local password hashes.

Traffic capture during the lab

Result

  • Root access obtained via UnrealIRCd
  • Meterpreter session established
  • Local hashes recovered

Notes

Metasploitable is intentionally vulnerable, but the process still matters. The value here is getting comfortable with the full flow: recon → exploitation → post-exploitation.
