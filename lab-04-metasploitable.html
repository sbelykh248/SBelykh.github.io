Lab 04 – Metasploitable Exploitation

Case Study: Controlled Attack Chain Against a Vulnerable Training Target

July 2026 · Intermediate Offensive Fundamentals

1. Context

Offensive security training depends on safe targets. Metasploitable is intentionally vulnerable so the attack process can be studied without harming real systems.

This lab follows a complete chain: prepare the environment, identify an exposed service, exploit it, gain control, and collect information after access.

Learning level: Intermediate
Focus: Attack process, service exposure, post-exploitation basics

2. Core Concepts

  • Attack surface: the set of exposed services and entry points
  • Vulnerable service: a running program with a known weakness
  • Exploitation: using that weakness to gain unauthorized control in a lab setting
  • Meterpreter / session control: interactive access after exploitation
  • Post-exploitation: actions taken after access is obtained

3. Environment

  • Attacker: Kali Linux
  • Target: Metasploitable 2
  • Platform: Oracle VirtualBox
  • Shared lab network between both systems

4. Procedure

Step 1 – Prepare the attacker system

Kali Linux was prepared as the offensive workstation for scanning and exploitation.

Kali Linux desktop used for the exercise

Step 2 – Confirm local lab services

Local service checks were performed during setup to ensure the attacker environment was functioning as expected.

Local web response on Kali

Additional local page used during setup verification

Step 3 – Identify a vulnerable service

The target was reviewed for exposed services. UnrealIRCd was identified as a weak entry point. In simple terms, an open service is a door; a vulnerable service is a door with a known bypass.

Step 4 – Exploit the service

Metasploit was used to exploit UnrealIRCd and establish remote access to the target system.

Step 5 – Observe network activity

Traffic was captured during the exercise to connect exploitation activity with observable network behavior.

Packet capture during the lab

Additional capture view during testing

Step 6 – Post-exploitation

After access was obtained, local system information and password hashes were collected. This stage focuses on what can be learned after the initial foothold.

5. Analysis

The value of this lab is procedural. Metasploitable is designed to be weak, so difficulty is not the point. The point is executing a clean sequence:

  1. prepare
  2. discover
  3. exploit
  4. gain control
  5. collect information

That sequence is the foundation for more advanced offensive labs.

6. Conclusion

Remote access was obtained, control was established, and post-exploitation collection was completed in a controlled virtual environment.

Main takeaway: offensive fundamentals are process skills. Tools change; the chain of discovery, exploitation, and post-access analysis remains consistent.
